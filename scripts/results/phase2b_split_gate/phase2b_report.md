| C2 feature mean | KS D (clip-level) | 0.15 | 0.3 |

| C5 silence drop spread | max-min across splits | 0.02 | 0.05 |
| C5 dB-floor fraction | per split | 0.05 | 0.2 |
| C5 ceiling saturation | per split | 0.01 | 0.05 |
| C5 padding | max clip pad_fraction | > 0.00 | > 0.10 |
| C5 non-finite | any | - | any |

KS tests use clips as the independent unit (windows within a clip are
correlated). Comparisons are always train vs val and train vs test.

Notes:
- Silence-drop rates are the Phase 2A quiet-window removals (-60 dBFS);
  the spread across splits is the balance metric.
- floor = values at the frozen -100 dBFS bottom (digital silence);
  ceiling = values saturated at 1.0 (content above the train dB max).
- Padding: the Phase 2A pipeline never pads (partial tail windows are
  dropped), so pad_fraction must be 0; truncation at 15 s is documented
  per split.
